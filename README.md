# Only the Shadow Knows: Secrets of the Fox Inn

An award-winning dual-character VR puzzle adventure built in Unity. Players switch between a hedgehog collecting memory shards and a fox who repositions objects to create safe shadow paths. Recover enough shards to uncover the complete story.

![Only the Shadow Knows gameplay](https://raw.githubusercontent.com/Xwen66/Portfolio/main/PortfolioMaterial/OnlyTheShadowKnows_image1.jpg)
